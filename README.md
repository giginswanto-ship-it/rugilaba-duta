# Laporan Laba Rugi Konsolidasi Multi-Unit

Aplikasi dinamis dan interaktif untuk simulasi serta pelaporan keuangan konsolidasi 3 unit usaha:
1. **Shop & Drive** (Otomotif & Fast Moving Parts)
2. **Snaprint Grand Wisata** (Digital Printing Large Format & Outdoor)
3. **Snaprint Zamrud** (Production Press A3+, Copy Center & Retail Merchandise)

## 🚀 Fitur Utama
- **Simulasi Laba Rugi Komparatif Realtime:** Update angka omzet, potongan, dan HPP untuk melihat margin kotor, EBITDA, EBIT, dan Laba Bersih Konsolidasi seketika.
- **Rincian Biaya Operasional (OPEX) Lengkap:** Disesuaikan secara rinci berdasarkan spesifikasi operasional masing-masing unit usaha.
- **Jadwal Penyusutan Aset Tetap:** Mengikuti pedoman fiskal perpajakan UU HPP No. 7/2021 (Garis Lurus Kelompok 1 & 2).
- **Simulasi & Komparasi Skema PPh:** Menghitung perbandingan riil PPh Final UMKM 0,5% (PP 55/2022) vs PPh Badan Umum (Ps. 31E).
- **Cetak & Export PDF:** Tata letak siap cetak untuk laporan eksekutif.

## 💻 Cara Menjalankan
Buka file `index.html` atau `aplikasi_laporan_konsolidasi.html` langsung di peramban web (Google Chrome / Microsoft Edge / Firefox).
