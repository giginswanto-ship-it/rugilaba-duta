Panduan Akses di Perangkat Lain (HP / Tablet / Laptop):
  • Akses Online (GitHub Pages / Web): Buka repositori ini di browser HP. Semua formulir dan kalkulasi siap digunakan tanpa instalasi.
  • Sinkronisasi Antar Device: Tekan tombol Ekspor Backup Data (.JSON), kirim berkas via WA/Drive ke HP, lalu tekan Impor Data Perangkat Lain di browser HP.
  • Integrasi Database Server: Unduh berkas .sql dan eksekusi pada phpMyAdmin / MySQL Workbench server Anda.
